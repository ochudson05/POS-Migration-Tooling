Menu Hauler Tool Map

Every tool in Menu Hauler: where it lives, what it can do and how it gets there. It's a set of web tools for setting a hospitality venue up on Oolio One, from looking the venue up to the import spreadsheet and the go-live pack.

What's new

Added on 16–17 November 2026. Each change also appears on its tool's card below, marked New.

Where everything runs

The website and all shared data live on Cloudflare. The Google server is optional: it makes reading menus from websites and photos better, and if it's off every tool falls back to its built-in readers.

The six tools

All six ship in one page, the launcher, as banner tabs. Each card shows where the tool lives, what it can do, the steps it runs through and what it costs.

Ve

Venues

Search the venues the team has already saved
Launcher tab 1venue-search.jsreads D1 records

What it can do

  • Search by name, organisation, suburb, ABN, legal name, owner, phone or email
  • Filter by stage, go-live soon, overdue steps and "mine"
  • Open a venue in any tool
  • Not found: add it, or send it to Restaurant Lookup

How it works

Type a search→Saved records /api/db→Filters→Active venue in every tool
Cost: free. It only reads saved records.
RL

Restaurant Lookup

A venue profile from a name and a suburb
Launcher tabrestaurant-lookup.htmlWorker calls Google, ABN, Firecrawl

What it can do

  • Google listing, opening hours, reviews and website
  • ABN and legal name
  • POS and online-ordering tech the venue uses
  • Delivery-app links, plus a short Claude summary when AI is on

How it works

Name + suburb→Google Places→Website via /api/fetch→ABN Lookup→Firecrawl last resort→Saved venue profile
Cost: Google Places 1,000 free a month · ABN free · Firecrawl about 13–23 credits, only when nothing else works. Results cached 14 days.
MC

Menu Converter

Menu Reader 2.0: any menu into the Oolio One import CSV
Launcher tabmenu-converter.htmlmenu-knowledge.jsserver scraper + OCR

What it can do

  • Read PDF, Word, Excel, photos and web addresses
  • "Find all menus": website, Hungry Hungry, me&u/Mr Yum, DoorDash, Uber Eats
  • NewRead Redcat onboarding workbooks (MENU and FREE TEXT sheets)
  • NewRead OrderMate exports: inactive items left out, pluses → "Add X", minuses → "No X", plus a modifier sheet (XLSX)
  • NewPrice lists as extra columns, from Oolio files or one OrderMate export per price level
  • NewTakeaway / dine-in sizes split into a Takeaway price list; filler sizes dropped; kids items become a Kids Size (tick box)
  • Sort into categories, food/drink, printers, sizes and modifier groups
  • Pre-flight check, menu changes vs last version, spirit brands, standard option groups
  • Price editor, price request sheet, no-price override, session restore

How it works

Files, POS exports (Oolio, OrderMate, Redcat) or web addresses→Built-in parsersorServer scraper + OCRorFirecrawl (capped)→Trained rules from ~220 venues→Review + checks→Oolio import CSV
"Check against the original" (AI flags differences between a photo and the list; it never fixes) is built but hidden until an API key is set.
Cost: free readers first · Firecrawl capped per search · AI only if the owner switches it on.
PF

Photo Finder

A photo for every product on the menu
Launcher tab (in a frame)photo-finder.htmlbrowser + /api/fetch

What it can do

  • Take an Oolio product export and find one photo per product
  • Prefer the venue's own photos over stock
  • Fall back to free photo libraries
  • Save a folder or a ZIP, with a credits file for each photo

How it works

Product export→Venue's own: Hungry Hungry, website, Uber Eats, DoorDash→Pexels, Pixabay, Openverse, Wikimedia→Folder or ZIP + credits
Cost: free libraries · DoorDash about 5 Firecrawl credits. Searches cached 14 days.
PE

Photo Editor New

One photo at the exact size you need
Photo Tools menuphoto-editor.htmlbrowser only

What it can do

  • Size presets (Oolio 1000 × 1000 square, landscape, portrait) or a custom size
  • Fill and crop, or fit the whole photo on white, black, a colour, blur or transparent
  • Drag, zoom, rotate, flip and adjust brightness, contrast and saturation
  • Save as JPEG, PNG or WebP under a file size limit (2 MB by default)

How it works

One photo (file or paste)→Frame it in the browser→Download at the chosen size
Cost: free. The photo never leaves the browser.
ST

Setup Tracker

The Config Recap Checklist for each venue, through to go-live
Launcher tabsetup-tracker.htmlrecords in D1

What it can do

  • Steps, owners and due dates, with links to help.oolio.com guides
  • NewDevices and printers read from a hardware diagram without AI, recognising everything on shop.oolio.com
  • New"Read with AI" tick box to send diagram pictures straight to Claude
  • Staff list, brand, Board view, organisations (groups of venues)
  • Go-live pack as a Word file
  • Customer intake link (30 days) and backup / restore of records

How it works (hardware diagram)

.drawio labelsorServer OCR→Diagram rules + Oolio shop catalogue→Claude only if rules find nothing (or Read with AI is ticked)→Device plan in the checklist
Cost: free.
IW

Image to Word

Photos, scans and PDFs into an editable Word file
Launcher tabimage-to-word.htmlpdf.js for PDFs

What it can do

  • Turn a photo or scan of a document into formatted text
  • Read PDFs page by page
  • Save a .docx you can edit
  • New"Read with AI" tick box (off by default). With AI on, text is grouped into headings, bullet lists and tables

How it works

Image or PDF→AI off: server OCR, else Tesseract in the browserorAI on: Claude, falling back to OCR→.docx
Cost: free, unless Claude is switched on for you.

Who can do what

OwnerEverything. The only one who can make admins, change allowed domains, turn AI on and choose who may use it.
AdminOpens /admin and manages members.
MemberUses the tools. Can be limited to some tools, set to view-only, have Firecrawl off, or be blocked.
