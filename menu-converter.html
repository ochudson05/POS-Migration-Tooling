Menu converter → Oolio One

Upload a Square or Lightspeed export, an Oolio pre-work spreadsheet, any spreadsheet a customer made, a menu PDF, a web page or a photo of a menu. You can add several at once, for example a product list and a modifiers sheet. You get one clean file in the Oolio One product import format. Spreadsheets, PDFs and web pages are read in your browser and never leave it. Menu photos and scanned PDFs are sent to Claude to be read.

1. Source files

Menu photos and scanned PDFs are read by Claude, which uses a little of your own Claude usage. The first time, you’re asked to allow it. Take photos straight on, in good light, one page at a time.
On the shared claude.ai page, web pages are read with your Firecrawl connector (add it once in claude.ai Settings → Connectors). A venue’s homepage is enough: up to 3 of its menu pages and menu PDFs are opened too, and Claude reads the menu, using a little of your Claude usage. Pages are read for free first (directly, or with the Claude app’s browser when this page is open in the Claude app); Firecrawl is only used for pages that can’t be read that way, at most 3 times per site. Results are kept for 7 days, so reading the same site again is free.
Menu scraper service
If you run the menu scraper (the menu-scraper folder), web pages are read through it first. It finds the site’s menu pages and PDFs, loads pages that need JavaScript, and reads the menu with Claude when it’s set up to.

2. Settings

Measured By

Items sold by the unit leave Measured By, Default Value and Unit blank. An item is only given a measure when its name, size or category shows it is poured. Draught beer (pot, middy, schooner, pint, jug), wine by the glass, spirit nips and anything with a poured volume such as “Glass 150ml” or “(30ml)” is measured by volume. Bottles, cans and packs stay as units. Change the result for a whole category in step 3.

3. Categories

Rename a category and set its printer profile, reporting group and Measured By. “As in file” keeps the printer each row gave. “Auto” works out the value for each item from its name, category and description, so a cocktail in a “Specials” category still goes to the bar as a Beverage.

4. Variants & modifier groups

Variants are for sizes only (Small / Medium / Large Latte, Pint / Schooner). Anything else becomes one product with a modifier group: Vanilla, Chocolate and Strawberry Milkshake become a Milkshake product with a “Milkshake Flavours” group. When options cost different amounts, the product takes the lowest price and each modifier adds the difference. Change how any group is handled, rename the product or the group, or add a group by keyword.

5. Standard option groups

Add common modifier groups such as steak cook, milk choice and spirit mixers. Each group links to the products whose name or category matches its keywords. Groups that match products on this menu start ticked, except Removals. Groups already in your files start unticked. Open “Edit” to change the options, prices, rules, keywords or linked products. Prices are typical Australian prices, so check them with the venue. Dietary codes printed on the menu, such as GF and V, still go in the Dietary Tags column. The Dietary Requirements group is linked to every food item so staff can record a customer’s needs (gluten free, vegan, nut free…), and Dietary Swaps adds paid swaps such as a gluten free base.
